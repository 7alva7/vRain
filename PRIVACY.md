# JinNang Privacy Policy

**Last updated: June 2026**

## Data Collection

JinNang does **not** collect, store, or transmit any personal data.

- No user accounts
- No analytics or tracking
- No usage logging
- No device identifiers collected

## On-Device Processing

All AI inference runs **entirely on your device**. Your conversations, prompts, and generated content never leave your iPhone.

## Network Requests

JinNang makes network requests only in these limited scenarios:

1. **App Store Purchase Verification**: Standard StoreKit transaction verification required by Apple for In-App Purchases.
2. **Model Download**: Optional — users manually download model files from external links via Safari.
3. **Time Verification**: Only when using the `/cheat` feature for test access validation. Normal use involves zero network requests.

## Third Parties

JinNang does not share data with any third party.
